Setup notes per brand

Samsung: a "Allow connection?" popup appears on the TV — press Allow.

LG webOS: accept the pairing prompt on screen.

Roku / Roku TV: enable Settings ▸ System ▸ Advanced ▸ Control by mobile apps ▸ "Network access" = Enabled. Volume works on Roku TVs only.

Amazon Fire TV: Fire TV talks raw TCP, which a browser can't reach. Run node firetv-bridge.js <TV-IP> on a computer on the same Wi-Fi, then enter the TV IP and that computer's IP. Power needs HDMI-CEC enabled on the TV.

Sony BRAVIA: Settings ▸ Network ▸ Home network ▸ IP control ▸ Authentication → "Normal and Pre-Shared Key", then enter that key below.

Vizio SmartCast: open https://TV-IP:7345 in this browser once and accept the certificate, then Connect — the TV shows a 4-digit PIN.

Panasonic: enable "Network control" / VIERA remote in the TV's network menu. Basic support.
